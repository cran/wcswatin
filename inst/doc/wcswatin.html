Preparing weather and climate inputs with wcswatin

wcswatin prepares weather and climate data for workflows that need SWAT-ready inputs. This vignette uses the small files shipped in inst/extdata to show the main object shapes and processing steps. The pkgdown site includes longer articles with a production-size ERA5-Land case study.

library(wcswatin)

Workflow overview

The package provides complementary workflows for gridded climate products and station observations. The first route extracts and aggregates raster values by study-area cell. The second prepares station series for quality control and trend-surface interpolation. Both routes produce SWAT-ready time-series files and support optional summaries or point-based comparison.

Inspect and load inputs

This is usually the first check after downloading or receiving a NetCDF file, because n_layers, time_start, time_end, and time_resolution determine whether the next step starts from daily layers or from an hourly workflow. var_names() returns just the data variable names.

Extract raster values at reference points

tbl_from_references() extracts gridded values at reference point locations. The points can be a table path, a data.frame, an sf object, a SpatVector, or a vector file accepted by input_vector().

station_values <- tbl_from_references(
  raster_file = daily_cube,
  ref_points = stations_file,
  prefix_colname = "t2m"
)

dim(station_values)

The result has one row per raster layer and one column per reference point. This shape is useful for comparing gridded products with station records after the time steps have been aligned.

Aggregate hourly files to daily files

daily_aggregation() works on folders of SWAT-style time-series files. The example below creates one hourly table and aggregates it to two daily values.

hourly_folder <- file.path(tempdir(), "wcswatin_hourly")
daily_folder <- file.path(tempdir(), "wcswatin_daily")
dir.create(hourly_folder, showWarnings = FALSE)

hourly_values <- data.frame(t2m = seq(280, 303, length.out = 48))
utils::write.table(
  hourly_values,
  file.path(hourly_folder, "t2m_20251001.txt"),
  row.names = FALSE,
  sep = ","
)

daily_aggregation(
  folder_in = hourly_folder,
  folder_out = daily_folder,
  from = "2025-10-01 00",
  to = "2025-10-02 23",
  drop_first_record = FALSE,
  aggregation_function = mean
)
#>   |                                                                              |                                                                      |   0%  |                                                                              |======================================================================| 100%

input_table(file.path(daily_folder, "t2m_20251001.txt"))
#>         t2m
#>       <num>
#> 1: 285.6277
#> 2: 297.3723

For accumulated variables timestamped at the end of the accumulation period, use mode = "value_at_hour". For ERA5-Land-style daily accumulated values stored at 00:00, keep value_hour = 0 and include the closing 00:00 record in the input period.

accumulated_folder <- file.path(tempdir(), "wcswatin_accumulated")
dir.create(accumulated_folder, showWarnings = FALSE)

accumulated_values <- data.frame(tp = seq_len(24))
utils::write.table(
  accumulated_values,
  file.path(accumulated_folder, "tp_20251001.txt"),
  row.names = FALSE,
  sep = ","
)

value_hour_folder <- file.path(tempdir(), "wcswatin_value_hour")

daily_aggregation(
  folder_in = accumulated_folder,
  folder_out = value_hour_folder,
  from = "2025-10-01 01",
  to = "2025-10-02 00",
  drop_first_record = FALSE,
  mode = "value_at_hour",
  value_hour = 0
)
#>   |                                                                              |                                                                      |   0%  |                                                                              |======================================================================| 100%

input_table(file.path(value_hour_folder, "tp_20251001.txt"))
#>       tp
#>    <int>
#> 1:    24

Station tables

Station files can be consolidated into one table for quality checks and simple summaries.

station_folder <- system.file("extdata/pcp_stations", package = "wcswatin")

pcp_table <- files_to_table(
  files_path = station_folder,
  files_pattern = "^p-",
  start_date = "2002-01-01",
  end_date = "2002-01-31",
  na_value = -99,
  neg_to_zero = TRUE
)

The inverse operation writes each station column back to a separate file.

station_out <- file.path(tempdir(), "wcswatin_station_files")

table_to_files(
  table = pcp_table[, -1],
  folder_path = station_out,
  first_date = "20020101",
  file_extension = "txt"
)

head(list.files(station_out))
#> [1] "p-1553003.txt" "p-1554006.txt" "p-1555005.txt" "p-1556007.txt"
#> [5] "p-1653002.txt" "p-1653004.txt"

point_to_daily() reorganizes station observations into one table per day. It is commonly used before spatial interpolation from stations.

daily_tables <- point_to_daily(
  my_folder = station_folder,
  start_date = "20020101",
  end_date = "20020131"
)

save_daily_tbl(
  tbl_list = daily_tables,
  path = file.path(tempdir(), "wcswatin_daily_station_tables")
)

Variable derivation

The package also includes helpers for deriving SWAT weather variables:

  • unit_converter() applies a transformation to all values in matching files;
  • rh_calculator() derives relative humidity from dewpoint and air temperature;
  • windspeed_calculator() derives wind speed from wind components.

For example, a Kelvin-to-Celsius conversion can be applied to a folder of files.

celsius_folder <- file.path(tempdir(), "wcswatin_celsius")

unit_converter(
  folder_in = daily_folder,
  folder_out = celsius_folder,
  FUN = function(x) x - 273.15
)
#>   |                                                                              |                                                                      |   0%  |                                                                              |======================================================================| 100%

input_table(file.path(celsius_folder, "t2m_20251001.txt"))
#>         t2m
#>       <num>
#> 1: 12.47766
#> 2: 24.22234
